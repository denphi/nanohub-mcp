# Supported Units

Units are grouped by physical quantity. `convert_units` only converts
between two units in the same group.

## Length

| Unit       | Symbol     | Meters       |
| ---------- | ---------- | ------------ |
| meter      | `m`        | 1            |
| micrometer | `um`       | 1e-6         |
| nanometer  | `nm`       | 1e-9         |
| angstrom   | `angstrom` | 1e-10        |

## Energy

| Unit          | Symbol | Joules              |
| ------------- | ------ | ------------------- |
| joule         | `J`    | 1                   |
| electron-volt | `eV`   | 1.602176634e-19     |

## Temperature

| Unit    | Symbol | Notes                    |
| ------- | ------ | ------------------------ |
| kelvin  | `K`    | absolute scale           |
| celsius | `C`    | `K = C + 273.15`         |
